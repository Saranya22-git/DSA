# **Computer and Programming Foundations**

## **Introduction to Computers**

### **Computer**

**What is a Computer?**

*A Computer is an electronic programmable device that accepts data as input, processes it according to a set of instructions, stores it if required, and produces meaningful information as output.*

---

**Why is it called an electronic device?**

*Because it works using electricity and electronic circuits.*

---

**Why is it called programmable?**

*Because the same computer can perform different tasks by running different programs without changing its hardware.*

---

**Four Basic Functions**

**IPSO Cycle**

1. **Input:** *Receives data*
2. **Processing:** *CPU processes data*
3. **Output:** *Displays the result*
4. **Storage:** *Saves data for future use*

**Example:** *Calculator*

- *Input → 5+10*
- *Processing → CPU performs addition*
- *Output → 15*
- *Storahe → Optional (e.g., calculation history)*

---

### **Evolution of Computers**

**Why did computers evolve?**

- *Think about mobile phones. 20 years ago → Keypad Phone, Today → Smartphone.*
- *Why? Because people wanted More speed, More memory, Smaller devices, Better performance, Lower cost. Computers evolved for the same reason.*

---

**What is a Computer Evolution?**

- *Computer evolution is the development of computers over time from large, slow, expensive machines to small, fast, powerful, and affordable systems.*
- *Computers are divided into five generations based on the technology used.*

1. **First Generation (1940-1956)**

    **Technology Used:** *Vacuum Tubes*

    *A Vacuum Tube acted like an electrnoic switch.*

    **Problems:**

    - *Very large*
    - *Consumed huge amounts of electricity*
    - *Generated lots of heat*
    - *Slow compared to modern computers*
    - *Failed frequently*

    **Examples:**

    - *ENIAC*
    - *UNIVAC I*

---

2. **Second Generation (1956-1963)**

    **Technology Used:** *Transistors*

    *A Transistor replaced the vacuum tube.*

    **Advantages:**

    - *Smaller*
    - *Faster*
    - *More reliable*
    - *Less heat*
    - *Lower power consumption*

    **Examples:** *IBM 1401*

---

3. **Third Generation (1964-1971)**

    **Technology Used:** *Integrated Circuits (ICs)*

    *Instead of connecting thousands of transistors individually, many transistors were placed on a single chip.*

    **Advantages:**

    - *Much smaller*
    - *Faster*
    - *Cheaper*
    - *More reliable*

    **Examples:** *IBM System/360*

---

4. **Fourth Generation (1971-Present)**

    **Technology Used:** *Microprocessors*

    *The CPU was integrated onto a single chip. This is the biggest milestone because almost every modern computer uses a microprocessor.*

    **Advantages:**

    - *Personal Computers (PCs)*
    - *Laptops*
    - *Smartphones*
    - *Tablets*

    **Examples:**

    - *Intel Processors*
    - *AMD Processors*

---

5. **Fifth Generation (Present & Future)**

    **Focus:** *Instead of just increasing speed, computers now focus on intelligence.* 

    **Technologies**

    - *AI*
    - *ML*
    - *Robotics*
    - *NLP*
    - *Quantum Computing (emerging)*

    **Examples:**

    - *ChatGPT*
    - *Self-driving cars*
    - *AI assistants*

---

### **Characteristics of a Computer**

**What are Characteristics of a Computer?**

*Characteristics of a Computer are the special features or qualities they describe what a computer is capable of doing. There are 8 important characteristics.*

1. **Speed:** *A Computer can perform millions or billions of operations in one second. Modern processors execute billions of instructions per second.*

    **Example:** *Imagine adding 123456789 + 987654321 Human (May take 20-30 seconds) Computer (Less than a millisecond)*

    **Real-World Example:** *When you search on Google, Millions of web pages are searched almost instantly.*

---

2. **Accuracy:** *A Computer gives accurate results if the input and program are correct.*

    **IMP POINT:** *People often say "Computers never make mistakes." This is not completely true. A Computer follows instructions exactly. If Input is wrong, Program has bugs. The output will also be wrong. This is called **Grabage In, Garbage Out (GIGO)***

    **Example:** *If you write ```print(10/0)``` The computer doesn't guess what you meant. It reports an error because the instruction is invalid.*

---

3. **Diligence:** *A Computer can perform the same task repeatedly without getting tired or bored.*

    **Humans:** *Gets tired, Loses concentration, Makes mistakes.*

    **Computer:** *Can repeat the same operation millions of times with the same performance.*

    **Example:** *A Bank server processes transactions 24×7 without becoming bored.*

---

4. **Storage Capacity:** *A Computer can store a huge amount of data.*

    **Examples:** *Photos, Videos, Documents, Databases, Applications.*

    **Example:** *Your phone can store 20,000 photos, Hundreds of videos, Thousands of songs. The same principle applies to computers.*

---

5. **Automation:** *Automation is the ability of a computer to execute tasks automatically after receiving instructions, without continuous human intervention.*

    **Example:** *Washing Machine*

    *After selecting a mode, it automatically Washes, Rinses, Dries. Similarly, a computer follows instructions automatically.*

---

6. **Versatility:** *A Computer can perform many different types of tasks.*

    **Example:** *Today you can use the same laptop for Coding, Gaming, Watching YouTube, Editing Videos, Banking, Online Shopping, AI Development. One machine, Many purposes.*

---

7. **Reliability:** *A Computer produces consistent and dependable results.*

    **Example:** *If you calculate 25 × 40 today, tomorrow, or next month, the answer is always 1000.*

---

8. **Multitasking:** *Multitasking is the ability of a computer to perfrom multiple tasks or run multiple program simultaneously by sharing CPU time efficiently.*

    **Example:** *Imagine you're using your laptop. At the same time, you are Listening to spotify, Downloading a file, Writing Python code, Watching YouTube, Chatting on WhatsApp Web.*

---

    - *Satellite images*
    - *Wind speed*
    - *Air pressure*
    - *Temperature*
    - *Ocean currents*
    - *Humidity*

    *This involves billions of calculations. A normal laptop cannot process all this data efficiently. A Supercomputer is desugned for this type of work.*

    **Characteristics**

    - *Fastest type of computer*
    - *Performs complex calculations*
    - *Very expensive*
    - *Uses thousands of processors/cores working together*
    - *Requires large amounts of electricity*
    - *Used by research organizations*

    **Applications**

    *Supercomputers are used in:*
    - *Weather forecasting*
    - *Space research*
    - *Scientific simulations*
    - *Artificial Intelligence*
    - *Medical research*
    - *Nuclear research*

    **Examples:** *Frontier, Fugaku*

---

2. **Mainframe Computer:** *A Mainframe Computer is a powerful computer designed to process a large number of transactions and support thousands of users simultaneously.*

    **Why do we need a Mainframe?**

    - *Everyone is Logging in, Paying fees, Downloading receipts. Can a normal laptop handle all these users? No. The system would crash. A mainframe is designed to handle thousands or even millions of users at the same time.*

    **Characteristics**

    - *Supports thousands of users simultaneously*
    - *Processes millions of transactions*
    - *Highly reliable*
    - *Large memory and storage*
    - *Very secure*

    **Characteristics**

    - *Medium processing power*
    - *Supports multiple users*

#### **Classification of Computers Based on Data Handling**

*Data Handling refers to how a computer accepts, processes, and represents data. Based on this, computers are classified into three types.*

1. **Analog Computer:** *An Analog Computer is a computer that processes continuous data or continuously changing physical quantities.*

    **What is Continuous Data?**

    *Continuous Data is data that can take any value within a range.*

    **Examples:** *Temperature, Speed, Pressure, Voltage, Time, Weight.*

    *For example, The temperature of a room can be 30°C, 30.1°C, 30.15°C, 30.156°C. There is no limit to the number of values between 30°C and 31°C. This is called Continuous Data.*

    **Characteristics**

    - *Works with continuous data*
    - *Produces approximate results*
    - *Very fast for measurement tasks*
    - *Used mainly for measurement and control systems*

    **Examples:**

    - **Analog Clock:** *The hands move continuously, not in jumps*
    - **Mercury Thermometer:** *Temperature rises continuously*
    - **Car Speedometer:** *The needle moves smoothly from 0 to 100 km/hr*
    - **Pressure Gauge:** *Measures continuously changing pressure*

---

2. **Digital Computer:** *A Digital Computer is a computer that processes discrete data (binary data) and performs calculations using 0s and 1s.*

    **What is Discrete Data?**

    *Discrete Data consists of separate, distinct values. It does not have infinite values between two numbers.*

    **Examples:** *Number of students in a class 45, 57, 68 not 24.5 students*

    **Characteristics**

    - *Processes discrete data*
    - *Uses binary (0 and 1)*
    - *High accuracy*
    - *High Speed*
    - *Stores large amounts of data*
    - *Can perform arithmetic and logical operations*

    **Applications**

    - *Education*
    - *Banking*
    - *Business*
    - *Programming*
    - *Gaming*
    - *AI*
    - *Data Science*
    - *Web Browsing*

    **Examples:** *Almost every modern computer is a digital computer*
    - *Desktop*
    - *Laptop*
    - *Smartphone*
    - *Tablet*
    - *Calculator*
    - *ATM Machine*

---

3. **Hybrid Computer:** *A Hybrid Computer is a computer that combines the features of both Analog and Digital Computers.*

    **Why do we need a Hybrid Computer?**

    - *A patient's heartbeat is continuous. An ECG machine first measures the heartbeat. This is analog data.*
    - *But doctors don't look at electrical signals directly. The machine converts those signals into digital data so they can be displayed on a screen, stored and analyzed.*
    - *A Computer that does both is called a Hybrid Computer.*

    **How does a Hybrid Computer work?**

    *It combines two parts*

    1. **Analog part**
      
          - *Measures continuous data*
          - **Example:** *Temperature, Blood pressure, Heartbeat, Speed*

    2. **Digital part**

          - *Converts the measured data into digital form*
          - *Processes it*
          - *Stores it*
          - *Display the result*

    **Characteristics**

    - *Combines Analog and Digital computers*
    - *High accuracy*
    - *Fast processing*
    - *Used where both measurement and computation are required*

    **Applications**

    **Medical Equipment**
    - *ECG Machine*
    - *ICU Patient Monitoring System*
    - *CT Scan*
    - *MRI Machine*

    **Aviation**
    - *Aircraft control systems*

    **Scientific Research**
    - *Weather forecasting systems*
    - *Industrial process control*

### **Components of a Computer**

**What are Computer Components?**

*Computer Components are the physical and internal parts of a computer that work together to perform input, processing, storage, and output operations.*

**Major Components of a Computer**

```text
                 Computer
                    │
     ┌──────────────┼──────────────┐
     │              │              │
  Input Unit       CPU          Output Unit
                    │
          ┌─────────┴─────────┐
          │                   │
        Memory              Storage
```

*These are the five fundamental components.*

1. **Input Unit:** *The Input Unit is responsible for accepting data and instructions from the user and sending them to the computer for processing.*

    **Examples:** 

    - *Keyboard*
    - *Mouse*
    - *Scanner*
    - *Microphone*
    - *Webcam*

    *You type ```10 + 20```. The Keyboard sends this information to the computer.*

2. **CPU (Central Processing Unit):** *The CPU is the brain of the computer that processes data and executes instructions.*

    **Main Functions of CPU**

    - *Executes programs*
    - *Performs calculations*
    - *Makes logical decisions*
    - *Controls all other components*

3. **Memory:** *Memory stores data and instructions that the CPU is currently using.*

4. **Storage:** *Storage is used to save data permanently, even after the computer is turned off.*

    **Examples:** 

    - *HDD*
    - *SSD*
    - *USB Drive*

    *Your photos remain on your laptop after you shut it down because they are stored in storage, not in RAM.*

5. **Output Unit:** *The Output Unit displays the processed results to the user.*

    **Examples:**

    - *Monitor*
    - *Printer*
    - *Speaker*
    - *Projector*

    *You type ```10 + 20```. CPU Calculates 30. The monitor displays 30.*

---

**How all components work together?**

*Suppose you calculate ```25 + 15```*

**Step 1 - Input:** *Keyboard sends 25 + 15*

**Step 2 - Processing:** *CPU performs the calculation.*

**Step 3 - Memory:** *RAM temporarily stores the data while the CPU works*

**Step 4 - Output:** *Monitor displays 40*

*If you save the result in a file*
 
**Step 5 - Storage:** *The file is saved permanently on the SSD or HDD*

- *Scanner*

- *Hard Disk (HDD)*

  - *Windows*
  - *Android*

  - *YouTube*
  - *WhatsApp*

  - *Google Chrome*

---

*Harware and Software work together.*

**Example:** *You click Instagram.*

**Hardware:**
- *Finger touches screen*
- *CPU processes action*
- *RAM stores data*

**Software:**
- *Instagram app opens*
- *Displays feed*
- *Loads messages*

---

**Difference between Hardware and Software**

| Hardware                | Software                          |
| ----------------------- | --------------------------------- |
| Physical components     | Programs and instructions         |

### **System Software vs Application Software**

*Software is mainly divided into 2 types*

- *System Software*
- *Application Software*

1. **System Software:** *System Software is software that manages the computer hardware and provides a platform for running application software.*

**Examples of System Software:**

- *Windows*
- *Linux*
- *macOS*
- *Android*
- *Device Drivers*
- *Utility Programs (Disk Cleanup, Antivirus, Backup Tools)*

**Functions of System Software**

- *Manages CPU*
- *Manages Memory*
- *Manages Storage*
- *Controls Input/Output Devices*
- *Runs Applications*

---

2. **Application Software:** *Application Software is software designed to help users perform specific tasks.*

*Suppose you want to Write a document you use application such as Microsoft Word, Watch YouTube you use application Google Chrome. These are Application Software.*

**Examples:** 

- *Microsoft Word*
- *Microsoft Excel*
- *Google Chrome*
- *VLC Media Player*
- *Adobe Photoshop*
- *WhatsApp*
- *Zoom*

---

**Comparison**

| System Software                      | Application Software        |
| ------------------------------------ | --------------------------- |
| Manages hardware                     | Performs user tasks         |
| Runs when the computer starts        | Runs when the user opens it |
| Provides a platform for applications | Depends on system software  |
| Essential for computer operation     | Used for specific tasks     |
| Example: Windows, Linux              | Example: Chrome, MS Word    |

### **Firmware**

**What is Firmware?**

*Firmware is a special type of software that is permanently or semi-permanently stored in non-volatile memory (such as ROM or Flash memory) and controls the basic functions of a hardware device.*

---

*Every hardware device needs basic instructions to start working. For example, When you press the power button on your laptop.*
- *How does the keyboard know how to work?*
- *How does the motherboard know where to start?*
- *How does the computer know to check RAM and storage?*

*These basic instructions are stored as Firmware.*

---

**Where is Firmware Stored?**

*Firmware is usually stored in ROM (Read Only Memory), EEPROM, Flash Memory.*

---

**Example:**

- *BIOS Firmware*
- *UEFI Firmware*
- *Router Firmware*
- *Printer Firmware*
- *Smart TV Firmware*
- *Camera Firmware*

---

**Characteristics**

- *Stored in ROM or Flash memory*
- *Starts when the device is powered on*
- *Controls hardware at a low level*
- *Can sometimes be updated (firmware update)*

---

*Firmware → System Software → Application Software*

*For example, when you press the power button:*

- *Firmware (BIOS/UEFI) starts first*
- *It loads the Operating System (System Software)*
- *Then you open Chrome or MS Word (Application Software)*

### **Input-Output (I/O) Devices**

**What is an Input-Output Device?**

*An Input-Output (I/O) Device is a hardware device that can both receive data from the user (input) and send processed data or information back to the user or another device (output).*

---

**Characteristics**

- *Performs both input and output functions*
- *Enables two-way communication*
- *Can send and receive data*
- *Hardware device*

---

**Common Input-Output Devices**

1. **Touchscreen:** *A Touchscreen is both an input and output device.*

    **Input:** *Detects finger touches or stylus input*

    **Output:** *Displays text, images, videos, and applications*

    **Examples:** *Smartphones, Tablets, ATMs, Self-service kiosks*

2. **Modem:** *A Modem is an input-output device that sends and receives data over the internet.*

    **Input:** *Receives internet data from the Internet Service Provider (ISP)*

    **Output:** *Sends your requests (such as opening a website) to the internet*

3. **Network Interface Card (NIC):** *A Network Interface Card (NIC) allows a computer to communicate over a network.*

    **Input:** *Receives network packets*

    **Output:** *Sends network packets*

4. **Storage Devices:**

    **Examples:**
    - *Hard Disk Drive (HDD)*
    - *Solid State Drive (SSD)*
    - *USB Flash Drive (Pen Drive)*
    - *Memory Card*

    **Input (Read):** *The computer reads data from the storage device*

    **Output (Write):** *The computer writes data to the storage device*

## **CPU**

**What is CPU?**

*The CPU (Central Processing Unit) is the primary component of a computer that executes instructions, processes data, and controls the operations of all other hardware components.*

---

**What does the CPU do?**

*The CPU performs three main tasks*

1. **Executes Instructions:** *It reads the instructions from a program and carries them out.*

    **Example:** *Add 10 and 20. The CPU performs the addition.*

2. **Processes Data:** *It performs calculations and logical operations.*

    **Example:** *Addition, Subtraction, Multiplication, Division, Comparisons (>,<,==)*

3. **Controls Other Components:** *The CPU coordinates and communicates with RAM, Storage (HDD/SSD), Keyboard, Mouse, Monitor, Printer, GPU.*

---

**Characteristics of CPU**

- *Processes instructions*
- *Performs arithmetic calculations*
- *Performs logical operations*
- *Controls all computer components*
- *Works at very high speed (billions of operations per second)*

---

**Where is the CPU located?**

- *The CPU is installed on the motherboard inside a special socket.*
- *It is usually covered by a heat sink, a cooling fan. These help prevent the CPU from overheating.*

---

**Common CPU Manufactures**

*Some well-known CPU manufactures are*

- **Intel:** *Intel Core i3, i5, i7, i9*
- **AMD:** *Ryzen 3, 5, 7, 9*

*These companies design CPUs for desktops, laptops and servers.*

## **Why is the CPU called the Brain of the Computer?**

*The CPU is called the Brain of the Computer because it processes instructions, makes decisions, performs calculations, and controls the operations of all other hardware components.*

---

**Why is it compared to the brain?**

*The CPU performs many important tasks*

1. **Receives instructions:** *It receives instructions from programs.*

    **Example:** *Open Google Chrome. The CPU receives this instruction.*

2. **Makes Decisions:** *The CPU decides what action should happen next.*

    **Example:** *If password is correct Login Else Show Error. The CPU evaluates the condition and decides which instruction to execute.*

3. **Performs Calculations:** *The CPU performs arithmetic operations.*

    **Example:** *20+30, 67-09 All these calculations are handled by the CPU.*

4. **Performs Logical Operations:** *The CPU compares values.*

    **Examples:** *10>5 Result True, 20==90 False*

5. **Controls Other Components:** *The CPU communicates with and controls RAM, SSD/HDD, Keyboard, Mouse, Monitor, Printer, GPU. It tells each component what to do and when to do it.*

---

*Suppose you open Microsoft Word*

**Step-1:** *You double-click the word icon (Mouse → Input)*

**Step-2:** *The CPU receives the instruction.*

**Step-3:** *The CPU loads the program from the SSD into RAM.*

**Step-4:** *The CPU starts executing word.*

**Step-5:** *The Monitor displays Microsoft Word.*
